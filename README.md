# 診所自動排班系統

> **2026-10-26 更新：** Google 登入與網站內表單讀寫已部署至 GAS 第 6 版；下方早期資料準備描述尚未完整更新，最新狀態請以 [GAS 說明](gas/README.md) 為準。另一台電腦使用、接續開發及對話連線方式見 [跨電腦交接指南](SECOND-COMPUTER.md)。自動排班引擎尚未啟用。

目前提供 **2026 年 11 月排班資料範本**，預留約 10 位員工與每日早／午／晚三班。GitHub Pages 已部署 RPG 首頁，提供「新增角色、角色設定、開始開戰、其他」四個入口。私人 Google Sheets 已建立；目前是資料準備階段，尚未連接自動排班引擎或 GAS。

網站：https://roroo0902.github.io/clinic-auto-scheduler/

首次使用可在首頁「試算表設定」貼上管理者持有的私人試算表連結。入口僅儲存在瀏覽器 localStorage，開啟試算表仍需 Google 權限；不會讀取或同步員工資料。新增角色與角色設定會說明應填分頁，再開啟試算表。

## 已確認的班別

| 代碼 | 班別 | 時間 |
| --- | --- | --- |
| A | 早班 | 08:00–12:00 |
| B | 午班 | 14:30–18:30 |
| C | 晚班 | 18:30–21:30 |

休息分鐘及實際計薪方式待確認，尚未將時段長度視為正式工時。空白／null 表示未知，不是零人、休假或休診。員工同日多班只算一天出勤。

## 現況

已製作資料範本、結構檢查、RPG 首頁及 32 分頁的私人 Google Sheets（30 個欄位契約分頁、使用說明、空白班表）。排班演算法、全部規則驗證、登入與 GAS 後端尚未完成。規則 47 仍待決策。正式部署依原規格第 43 條於完整測試及管理者核准後進行。

GitHub 只放無個資範本，真實員工、請假與班表資料應在受限資料庫填寫。請在私人試算表填寫，不要直接在 GitHub 填入個資。

GitHub Pages 設定：公開儲存庫、main 分支、/docs 目錄。docs/index.html、style.css、app.js 為靜態網站。變更推送後由 GitHub Pages 自動發布。
