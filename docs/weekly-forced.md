# 每週指定班別

管理者從「英靈編成 → 每週指定班別」設定每位員工星期一至日的完整班別。選早班只排早班；選休則不排班；未指定交由排班規則決定。範本從生效日起跨月沿用，特殊日期優先，選沿用每週可恢復範本。

設定只儲存規則，不直接更改月班表。請假、可排時段、允許班別及班次鎖定仍須遵守；衝突不得直接發布。原逐日指定保留，畫面標示為「至少包含」，需明確設例外才取代。

模組沿用獨立歷程工作表，採管理者權限、指紋、一次性預覽、原子儲存與寫後讀回，並接入自動排班、統計及智慧建議。先從最新完整雲端來源合併 `scripts/merge-weekly-forced.mjs`，再合併班表鎖定；勿覆蓋既有雲端來源。

本次模組由「說明指定班別」聊天完成，與班表鎖定及手機返回一起發布。桌面及 390px 手機預覽驗證只讀取／預覽正式資料；寫入、衝突及權限由隔離模擬測試驗證。班次鎖定另以隔離 Google 試算表實際寫入驗收。
