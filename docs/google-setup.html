Google Sheets 連線設定

管理者只需設定一次。每位使用者以自己的 Google 帳號授權；必須具備目標試算表的編輯權限。網站不保存密碼，存取權杖僅留在頁面記憶體。

  1. 在 Google Cloud Console 建立或選擇本專案，啟用 Google Sheets API。
  2. 開啟 Google Auth Platform，設定應用程式名稱、聯絡信箱與使用對象。個人 Gmail 使用 External；測試階段加入 ryan25620280@gmail.com 為測試使用者。正式開放其他人前依 Google 規定完成發布／驗證。
  3. 建立 OAuth Client：應用程式類型選「Web application」。Authorized JavaScript origins 填入 https://roroo0902.github.io。若需本機測試再加入使用的 localhost 來源（含連接埠）。
  4. 複製以 .apps.googleusercontent.com 結尾的 Client ID。不要複製 Client Secret。將 Client ID 填入網站編輯器的「Google 連線設定」，或交由管理者寫入 docs/google-config.js 供所有桌機共用。
  5. 回網站，按「連接／重新登入 Google」，選擇有權限帳號並由使用者確認授權。選擇現有列或新增資料，修改後按「預覽變更」，核對目的地、勾選確認，再按「確認並上傳」。

Google 授權包含試算表讀寫範圍；本站只針對設定的目的地送出請求。未設定 Client ID 前不能讀寫。Google Sheets 沒有此流程可用的原子比較交換：上傳前會比對最新資料，但請避免兩人同時編輯同一列。遇到網路中斷先重新讀取確認，不要直接重送。
