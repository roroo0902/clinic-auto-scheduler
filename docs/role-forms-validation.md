# 英靈編成表單驗收（2026-10-31）

修正新增員工因範本含公式而無法儲存的問題：一般欄位與公式複製使用同一個 Sheets 原子批次；公式由原生 PASTE_FORMULA 調整相對列參照。既有公式不可改寫、過期預覽、管理者權限及寫後讀回檢查均保留。

補上班次鎖定選單及中文欄位對照；選單不再把僅有 FALSE 的預先配置列當成資料。雲端 RPG 表單的基本資料區預設展開。

實際驗收涵蓋 11 個表單：員工基本資料、班次鎖定、允許班別、指定日期可排時段、每週固定時段、指定班別、排班偏好、班別組合順位、班別優先人員、請假申請、個人假日。使用停用虛構員工與 2030 年日期，共 13 次成功寫入；每項另以 Sheets 讀回並在新分頁重新開啟核對，109 個一般欄位一致，兩個公式另行檢查。測試資料已還原，正式月班表未修改。

雲端部署 v33 使用既有部署 ID 與原權限；瀏覽器先取得舊頁，稍後新分頁已確認載入新選單程式並只顯示有內容的記錄。這不代表測試了所有瀏覽器快取或登入情境。

公開來源與既有雲端 RPG 介面有歷史差異。不可用公開模板重建後直接覆蓋完整雲端來源；需先匯出最新雲端完整原始碼，再執行：

```sh
node scripts/merge-role-form-fixes.cjs latest-cloud.gs candidate.gs
```

合併器要求來源精確且唯一符合預期，已套用或其他版本會停止。私有備份、實際員工資料與驗收快照不納入此儲存庫。

本次來源回歸 113 項通過，另對完整雲端候選程式執行 7 項針對性檢查。這些驗收不等同正式排班參數已完整，也不代表各員工本人帳號皆已登入測試。
