# 允許班別：員工核取方塊設定

進入「英靈編成 → 允許班別」，勾選員工後，每人分別顯示七個班別組合。單班 A/B/C 與同日多班 AB/BC/AC/ABC 分開，勾選 A 與 B 不代表允許 AB。

畫面讀取目前啟用員工及選定生效日的個人設定；沒有個人設定時顯示「沿用全體設定」，沒有任何設定則顯示不允許。取消選取員工只收起卡片，不停用員工，也不刪除設定。只有本次選取的人員會送出儲存。

預覽列出每人的修改前後及適用期間，勾選確認後一次儲存並讀回。後端重新驗證管理者、員工啟用狀態、資料指紋、日期、組合及重疊期間。個人設定優先於全體預設。更新期間時保留前後未覆蓋的設定、其他員工、全體預設及備註；不新增或改寫班表。

## 維護與發布

- `gas/AllowedShifts.gs`：讀取、預覽、原子批次寫入及讀回。
- `gas/AllowedShifts.html`：人員核取方塊及個人班別卡片。
- `tests/allowed-shifts.test.cjs`：不同員工設定、期間保留、衝突、權限及讀回測試。
- `scripts/merge-allowed-shifts.cjs`：從剛匯出的完整雲端程式精確合併；保留較新的手機返回等功能。不要用舊本機 Portal.gs 整份覆蓋雲端。

執行 `node --test` 後，使用 `node scripts/merge-allowed-shifts.cjs latest-cloud.gs candidate.gs` 建立候選版，先在隔離副本驗證寫入，再更新既有 Apps Script 部署並重開正式入口驗收。

真實員工姓名與驗收副本 ID 不提交公開儲存庫。
