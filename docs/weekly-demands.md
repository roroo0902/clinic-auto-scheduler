# 每週固定人力需求

「每日人力與人數上限」月曆 → 選月份 →「每週固定需求 → 套用整月」。

每週一到日各有早、午、晚班，可選不套用、開診、休診。開診填最低、最高人數，理想可留空；休診套用為三個人數皆 0。「將週一設定複製到週二～週六」只修改畫面草稿。每週範本在確認後存到同一份 Sheet 的「每週固定人力需求」，可跨月沿用。

預設只填完全空白人數且未休診的班別；已有任一人數（包括 0）、休診或公式均保留。覆蓋模式會替換既有人數；特殊日期可填日數略過，例如 `1, 15, 28`。不套用的星期班別永遠不改。套用後可從月曆個別修改。

套用前顯示逐日、逐班前後人數與變更數。管理者勾選確認後，後端重新驗證角色、資料指紋、範本、公式與人數，再用同一個原子批次備份原需求、備份舊範本並更新。讀回成功才回報完成；預覽有效 10 分鐘，寫入前消耗單次 token，未知結果不自動重送。只修改人力需求與每週範本，不產生或發布員工班表，也不修改營業日曆。

部署必須先從 Apps Script 編輯器讀取最新完整來源，再執行 `scripts/merge-weekly-demands.mjs`。不要用本機舊 Portal 覆蓋雲端。新增檔案為 WeeklyDemands.gs/html；產生器只產生 UI，伺服器模組須一併加入雲端來源。

測試：`node --test tests/weekly-demands.test.mjs tests/demand-calendar.test.mjs tests/forms.test.mjs`。測試使用隔離記憶體 Sheet 模擬，涵蓋日曆映射、例外保留、批次讀回、失敗重送、角色撤銷、公式與重複資料。
