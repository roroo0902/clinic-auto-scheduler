# 班表批次鎖定

管理者在整體班表或我的班表按「批次選取日期」，勾選員工日期，按「批次鎖定」或「批次解除」，核對清單後確認。可全選目前顯示班表或取消全選；切換月份、員工、重新讀取後清空選取，避免誤用舊資料。一般員工只能查看鎖定標記。

每個選取項目包含員工、日期、目前班別與鎖定指紋。伺服器在 ScriptLock 內先核對全部項目，任一筆過期、重複或權限不符則整批不寫入；確認後以單一 Sheets batchUpdate 儲存，逐列讀回後再傳回更新班表。不會更動月班表、工時或班別。未排班日期亦固定其空白狀態。

讀回或網路失敗時畫面不宣稱成功，也不允許原預覽重送；請重新讀取確認。每批最多 1000 個員工日期。沿用既有三班 A/B/C 鎖定格式及自動排班限制。

部署時先匯出最新完整雲端程式，再執行 `node scripts/merge-batch-locks.cjs 最新來源.gs 輸出.gs`；不可用舊完整檔覆蓋其他改版。隔離測試來源不得部署至正式 /exec。
